# EduProcessorK2

**KUE-CHIP2の命令セットと動作仕様をVHDLで実装した教育用CPU**

## 1. 概要

EduProcessorK2は、KUE-CHIP2の命令セットおよび動作仕様に基づいてVHDLで設計した教育用CPUです。

CPUの内部構造、データの流れ、命令実行の仕組みを理解することを目的としています。

特に、命令の実行過程をフェーズ単位で観察できるように設計しており、コンピュータアーキテクチャやCPU制御回路の学習に利用できます。

Intel FPGA上で動作し、Quartus PrimeによるコンパイルおよびFPGAへの実装が可能です。

## 2. 設計の特徴

### KUE-CHIP2の仕様に基づくCPU

本CPUは、KUE-CHIP2の命令セット、アドレッシング方式、レジスタ構成、フラグ制御などの仕様を参考に実装しています。

CPUの主な構成要素は以下のとおりです。

- 命令レジスタ
- 演算論理回路（ALU）
- 各種レジスタ
- プログラムカウンタ
- メモリ制御回路
- 命令デコード回路
- 命令実行制御回路
- 入出力制御回路

### 命令実行フェーズに基づく制御

CPUの制御回路は、『KUE-CHIP2 教育用ボード リファレンスマニュアル』に記載された命令実行フェーズを基本として設計しています。

特に同マニュアル73ページの命令実行フェーズ図を参考に、各命令の実行に必要な制御信号をフェーズ単位で生成する構成としています。

命令実行の各段階を明確にすることで、CPUの内部動作を理解しやすい構造としています。

### 3つの実行モード

EduProcessorK2には、以下の3つの実行モードがあります。

| モード | 正式名称 | 動作内容 |
|---|---|---|
| SS | Start & Stop | CPUの連続実行を開始・停止する |
| SI | Single Instruction | 1命令を実行して停止する |
| SP | Single Phase | 命令実行の1フェーズを実行して停止する |

SIモードでは命令単位の動作を、SPモードでは命令を構成する各フェーズの動作を観察できます。

これにより、命令デコード、演算、レジスタ更新、メモリアクセスなどの処理を段階的に学習できます。

| ファイル | 内容 |

## 5. コンパイル方法

### 必要なソフトウェア

- Intel Quartus Prime Lite Edition 20.1.1
- ModelSim-Altera（シミュレーションを行う場合）

### ソースファイルの取得

以下のコマンドでリポジトリを取得します。

```bash
git clone https://github.com/wataruaoyama/EduProcessorK2.git
```

開発版を使用する場合は、次のコマンドで`develop`ブランチに切り替えます。

```bash
cd EduProcessorK2
git switch develop
```

### Quartusでのコンパイル

1. Quartus Primeを起動します。
2. `ayme0900.qpf`を開きます。
3. **Processing → Start Compilation**を実行します。
4. コンパイルが正常終了したことを確認します。

対象FPGAおよびピン配置は`ayme0900.qsf`に設定されています。

### FPGAへの書き込み

Quartus Programmerを使用し、対応するFPGAに`ayme0900.sof`または`ayme0900.pof`を書き込みます。

書き込みファイルは、対象デバイスおよび基板構成に適合したものを使用してください。

## 6. 動作検証

本プロジェクトでは、KUE-CHIP2の命令仕様に基づき、CPUの動作検証をしています。

主な検証対象は以下のとおりです。

- 各命令の実行動作
- 各種アドレッシング方式
- レジスタの更新と保持
- 条件フラグの更新と保持
- 命令実行フェーズの遷移
- 命令の連続実行
- SS/SI/SPの各実行モード

また、『KUE-CHIP2 教育用ボード リファレンスマニュアル』に記載されたサンプルプログラムによる動作確認を行っています。

なお、シミュレーションおよび実機試験による検証結果は、すべての動作条件における完全な互換性を保証するものではありません。
